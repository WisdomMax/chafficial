# 차마트 우대차량

고객 운영 배포: https://43d67fce.chamart.pages.dev (2026-10-30).

- SVG 스티커 ‘차마트 우대차량’과 차콜 방패 체크 아이콘. 차마트 직접 보유 표시이며 별도의 외부 인증을 주장하지 않는다.
- 기존 세 가지 카드 모두 동일 조건으로 형광 연두색 1px 테두리 적용.
- 기존 목록 안에서 직영 매물을 먼저 정렬한다. 선택한 가격·주행거리 정렬은 직영/일반 그룹 각각에 적용된다. 검색·필터 조건은 유지된다.
- OWNED / CHAMART_OWNED만 대상. 우선 노출 설정만 켜진 제휴 차량, 미분류, 판매 완료에는 스티커 없음.
- 소유 구분 변경 시 자동으로 다음 조회에서 표시 조건 변경. 운영 API 캐시는 최대 5분이다.
- 고객 Worker에서 미분류를 OWNED로 간주하던 응답 기본값을 UNKNOWN으로 변경했다. 기존 운영 DB 값은 수정하지 않았다.
- 로컬 관리자 master 등록·수정 시 ownership_type과 listing_ownership_type 동기화. D1 관리자 등록 API도 기존 두 필드 형식을 모두 처리한다. 관리자 등록 화면에 안내 문구 추가.

검증: Node에서 직영·제휴·미분류·판매완료 판별 및 정렬 검사, 모의 D1 등록 처리 검사 통과. 로컬 master 등록·소유변경은 메모리 DB로 검사 통과. 브라우저에서 370px와 세 가지 보기 방식의 가로 넘침 없음. 실제 chamart.cc에서 가격 정렬 후 일반 매물 뒤에 직영 매물이 섞이지 않고, 일반 매물에는 스티커가 없음을 확인했다.

운영 신규 매물 쓰기 테스트는 수행하지 않았다. manage.chamart.cc API 직접 조회는 403으로 차단돼 등록 저장까지 운영 검증하지 못했다. 관리자 프로젝트의 별도 운영 배포 및 로컬 백엔드 재시작은 수행하지 않았다. 등록 연동 코드는 로컬에서 검증된 상태다. 고객 운영 표시·정렬은 배포 및 확인 완료.
