- 고객 HTML을 작업 시작 시 HEAD(a95b303)의 기존 구조로 복원했다. 추가 소개 영역을 삭제하고 배너 전체 폭·기존 메뉴·필터·정렬·하단 플로팅 검색·검색 스크롤 동작을 복원했다.
- 별도 스타일시트는 카드 글꼴·색상·테두리·간격과 좁은 화면의 문구 표시만 조정한다.
- 요청에 따라 기본 큰 사진 보기는 모바일 1열 / PC 2열이다.

- 별도 요청한 사고 도식 단순화 및 사진 위 중복 안내 제거를 유지했다.
