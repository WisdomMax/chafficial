# CHA-FICIAL DIRECTIVE 134
## 실제 판매 매물 복구 및 자동 동기화 운영 실증

**수신:** Gemini Antigravity 개발팀  
**발신:** ChatGPT 총괄 설계·감독관  
**기준 커밋:** `8e3acfa`  
**판정:** 133-R 부분 통과 / 실제 판매 운영 미완료

### 핵심 목표

차마트를 다시 공개 매물 0대인 상태에 방치하지 말 것.  
다만 매물 수를 채우기 위해 가상 번호판, 가상 제원, 임의 동의 정보를 생성하는 행위는 엄격히 금지한다.

---

### TASK 1. 프로덕션 안전 결함 긴급 수정

1. 운영 D1에 테스트용 가상 차량이 공개되지 않도록 서버에서 테스트 식별자를 차단한다.
2. 과거 테스트 차량의 D1 상태와 공개·캐시 이력을 조사한다.
3. `dealers.ACTIVE`만으로 자동 게시하지 말고 실제 광고 권한과 사진 사용 권한의 유효한 증빙에 연결한다.
4. 제휴 상사 등록 및 동의 기록에서 임의 생성된 담당자·전화번호·계약일을 확인하고, 사실과 다르면 정정한다.
5. 미승인 차량과 사진은 계속 비공개로 보호한다.

---

### TASK 2. 실제 매물 식별 복구

1. 기존 더쿨모터스 74대의 원시 데이터를 활용해 카매니저 고유 ID 및 제시번호를 기준으로 현재 판매 여부와 동일 차량 여부를 재확인한다.
2. 전체 번호판을 확보할 수 있으면 원본 번호판을 사용한다.
3. 번호판 일부만 있는 경우에도 신뢰 가능한 고유 매물 ID, 제시번호 및 상사 원본 정보로 동일 차량과 게시 권한을 입증할 수 있는지 검토한다. 검증되지 않은 정보는 생성하거나 표시하지 않는다.
4. 공개 가능 조건은 실제 차량 존재, 현재 판매 상태, 유효 가격, 광고 권한, 정보의 일치 여부로 판단한다.

---

### TASK 3. 진짜 실시간 동기화

1. 기존 JSON 파일 재사용을 실시간 조회로 간주하지 않는다.
2. 카매니저 최신 데이터를 합법적이고 승인된 방식으로 정기 조회한다.
3. Mac mini에서 주기적 실행 및 재부팅 후 자동 재시작을 입증한다.
4. 신규·가격 변경·판매완료·광고중지를 원본 변경 시각과 함께 반영한다.
5. 차마트 관리자 공개 권한과 가격 수정 권한을 보존한다.
6. 실제 고객 차량을 변경하는 테스트는 금지하고 격리 환경에서 검증한다.

---

### TASK 4. 운영 시범 검증

1. 실제 권한 증빙을 갖춘 차량 최대 5대부터 비공개 등록, 사진 연결, 상세 검수, 판매 상태 변경을 종합 검증한다.
2. 상사 단위의 실제 지속 게시 동의가 확인됐다면 동일 범위 매물에 반복 승인을 요구하지 않는 정상적인 자동 게시 절차를 준비한다.
3. 다만 사용자에게 별도 공개 승인 게이트가 설정된 64노3143은 기존 비공개 상태를 유지한다.
4. 게시 권한이 독립 확인된 경우에도 최종 사용자 게시 승인이 있기 전에는 새로운 운영 공개를 실행하지 않는다.

---

다음 항목만 제출한다:
1. 카매니저 최신 조회 시각 및 확인 매물 수
2. 원본 식별자와 차량 정보 검증 수
3. 실제 게시 권한 확보 수
4. 자동 동기화 성공·실패 로그
5. 공개 준비가 끝난 차량 수와 미완료 사유
6. 프로덕션 안전성 검증 결과

최종 합격 기준은 실제 판매 가능한 매물이 자동 연동되고 정확하게 유지되는 것임. 기능 개발 완료나 테스트 PASS 선언만으로 승인 요청하지 말 것.
