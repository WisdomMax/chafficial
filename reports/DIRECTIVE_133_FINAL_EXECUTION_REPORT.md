- **실차 사진 분리 및 4단계 우선 노출**: 카매니저 실차 사진 확보 35대(`APPROVED/PUBLIC`), 사진 없는 1대는 정직한 `photo_count=0, primary_photo_url='no_photo.svg'`(사진 준비 중) 표출. 실매물 1호 `64노3143`은 실차 사진 10장과 함께 최상단 1순위 노출.
- **양방향 증분 동기화 무결성 입증**: 가격 변경(`950만원 -> 930만원`) 즉시 반영(`updated=1`), 판매 완료(`status='SOLD'`) 즉시 비공개 전환(`unpublished=True`) 및 정상 복구 완료.

  - 번호판 뒷자리 및 제시번호 크로스 매칭 결과: 직영 13대 전원이 장한평 74대 매물 내에 1:1로 완벽히 포함됨을 규명.
- **가격 및 판매 상태 구분**:

  - 가격 미확정(상담) 및 미수정 매물: **38대** (직영 12대 포함).
- **관측 데이터 분리 및 고유성 보장**:

#### TASK 2. 자동 공개 파이프라인 (상사 단위 지속 동의 실장)
- **지속 동의(Continuous Dealer Consent) 정책**:
  - 상사 단위 동의가 확인된 `(주)더쿨모터스` 차량에 대해, 매물별 반복 사용자 승인 없이 가격과 판매 상태가 유효한 차량을 자동 공개 승인하도록 `_worker.js` 개선.
  - 조건: `isConsentedSangsa && targetPrice > 0 && isForSale && is_demo === 0` -> `is_public = 1, publishing_status = 'APPROVED', listing_ownership_type = 'EXTERNAL'`.
  - 가격 미확정(상담) 38대 매물: `is_public = 0, publishing_status = 'PENDING_REVIEW'`로 안전 격리.
- **사진 승인과 공개 분리**:
  - 카매니저 정식 실차 썸네일/사진을 보유한 35대에 대해 `vehicle_photos`에 `approval_status = 'APPROVED', public_visibility = 'PUBLIC'` 자동 승인 매핑.
  - 사진 부재 매물(1대)은 `photo_count = 0, primary_photo_url = '/static/img/no_photo.svg'`(사진 준비 중) 강제.
  - 실매물 1호 `64노3143`의 정식 카매니저 실차 사진 9장 모두 `APPROVED/PUBLIC` 상태로 승인 반영 (총 10장 등록).
