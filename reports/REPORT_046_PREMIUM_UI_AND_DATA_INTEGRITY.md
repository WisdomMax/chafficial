## 1. 개요 및 달성 성과 요약

기존 임시 관리자 페이지 느낌을 전면 탈피하고, Linear / Vercel Dashboard 수준의 현대적인 프리미엄 B2B 운영 플랫폼으로 개편을 완료하였습니다.

1. **디자인 시스템 및 레이아웃 전면 쇄신 (046 & 046-A)**:
   - 다크 네이비(`#101A2A`) 고정 사이드바, B2B 틸 액센트(`#247D7C`), 라이트 그레이 배경(`#F5F7FA`) 적용.
   - 업무 성격별 메뉴 그룹화 (`OVERVIEW`, `OPERATIONS`, `GROWTH`, `CHANNELS`, `SYSTEM`) 및 미구현 기능 절제된 `준비 중` 뱃지 적용.
   - 불필요한 장식적 설명 문구를 일체 제거하고, 물음표(`?`) 툴팁 컴포넌트로 표준화.
   - 각 화면별 1개의 주요 행동(Primary Action) 버튼 강조 (`+ 차량 등록`, `+ 고객 추가`, `새 영상 만들기`).
   - 국토교통부 공식 행정 이전등록(298,293건) 및 데모 격리 표시 무결성 유지.

2. **전역 통합 검색 및 한글 초성 엔진 신규 구축 (046-B)**:
   - 한글 음절 초성 분해 알고리즘: `(code - 0xAC00) // (21 * 28)` 수학적 분해 및 U+1100대 첫가소리 자모와 U+3130대 호환 자모 완전 통일 매핑 (`LEAD_JAMO_TO_COMPAT`).
   - 초성 검색 완벽 지원: `ㅇㅂㄸ` 입력 시 `아반떼`, `ㄱㄹㅈ` 입력 시 `그랜저`, `ㅈㄴㅅㅅ` 입력 시 `제네시스` 실시간 즉시 매칭.
   - 유니코드 NFKC 정규화 + 영문 casefold + 다중 복합 키워드 검색(`아반떼 2023`) + 세부 상담 메모 본문 검색 지원.
   - 프론트엔드 테이블 컬럼 원클릭 정렬(차량명, 연식, 주행거리, 광고가격, 고객명, 희망예산) 및 화살표(`↕`, `↑`, `↓`) 인터랙션 완비.

3. **데이터 무결성 표준화 (046-C)**:
   - **금액**: 화면 표시 시 세자리 쉼표(`18,500,000원`), DB 저장 시 순수 정수(`18500000`) 파싱 및 저장.
   - **전화번호**: 화면 표시 시 하이픈 포맷(`010-1234-5678`), DB 저장 시 숫자만(`01012345678`) 정규화.
   - 프론트엔드 입력 이벤트(`input`) 및 백엔드 서비스 계층(`service.py`) 이중 검증 구축.

4. **보안 지침(12항) 엄격 준수**:
   - 관리자 비밀번호는 신규 암호학적 32자리 키로 교체되어 `.env`에 격리 보관되며, 본 보고서, 화면, 채팅 어디에도 노출되지 않음.
   - 비인가 `/api/search` 요청 시 HTTP 401 Unauthorized 차단 검증 완료.

## 3. 전역 통합 검색 (Universal Search) 아키텍처

### 3.1 한글 초성 분해 및 유니코드 정규화 구조
- **모듈 위치**: `src/chaficial/platform/search.py`
- **호환 자모 통일**: 유니코드 NFKC 정규화 시 발생하는 첫소리 자모(U+1100~U+1112)와 호환 자모(U+3131~U+314E) 간의 코드 불일치 문제를 `LEAD_JAMO_TO_COMPAT` 테이블을 통해 100% 호환 자모로 단일화.
- **초성 분해 수식**:
  $$\text{chosung\_index} = \lfloor(\text{code} - \text{0xAC00}) / 588\rfloor$$
- **복합 검색 및 엔티티 통합**:
  단일 검색어로 차량 재고(`Vehicle`), 고객 CRM(`Customer`), 상담 메모 본문(`Consultation`), 거래 내역(`Transaction`), 영상 프로젝트(`MediaProject`)를 병렬 탐색하여 단일 드롭다운에 카테고리별 제공.

## 4. 데이터 무결성 규칙 (046-C) 구현

### 4.1 금액 데이터 파싱 & 포맷팅
- **함수**: `parse_currency_amount(val)`, `format_currency_display(amount)`
- **규칙**:
  - `₩ 18,500,000 원` $\rightarrow$ 정수 `18500000`
  - `18500000` $\rightarrow$ `18,500,000원`
  - 화면 입력창: 숫자를 입력할 때마다 실시간 3자리 쉼표 자동 포맷팅 적용.

### 4.2 전화번호 정규화
- **함수**: `normalize_phone_number(raw_phone)`, `format_phone_display(phone_digits)`
- **규칙**:
  - `010-1234-5678`, `010 1234 5678`, `+82 10-1234-5678` $\rightarrow$ DB 저장: `01012345678`
  - DB 조회값 $\rightarrow$ 화면 표시: `010-1234-5678`
  - 화면 입력창: 숫자 입력 시 실시간 `010-XXXX-XXXX` 하이픈 자동 삽입.
