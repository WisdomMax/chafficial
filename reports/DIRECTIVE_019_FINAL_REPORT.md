## 4. 회신 CSV 입력 검증 체계 점검 결과

실제 딜러 회신 파일 인입 시 동작하는 안전 장치가 모두 구축되어 검증되었습니다:
1. **필수 인자 강제 (`is_pilot_actual=True`)**: 단순 파일 로드만으로 실제 평가로 오분류되지 않도록 명시적 인자 강제.
2. **입력값 정합성**: `dealer_verdict in ("BUY_REVIEW", "WATCH", "EXCLUDE")`, 금액 음수 입력 즉시 차단, 사유 공백 차단.
3. **제출 세션 식별자 (`submission_id`)**: 파일 내용 해시 기반 세션 식별로 동일 회신 중복 업로드 방지 및 후속 정당한 재평가 이력 보존.
4. **원본 보존 안전성**: 빈 파일(0 bytes) 및 손상 JSON에 대해 즉시 실행을 중단하고 기존 파일을 덮어쓰지 않는 안전성 확보.

## 5. 성과 지표의 엄격한 정의

딜러 회신 접수 후 산출될 성과 지표의 오해와 과장을 방지하기 위해 용어를 명확히 정의합니다:
- **딜러 동의율 (Dealer Agreement Ratio / `hit_ratio_pct`)**:
  - AI가 기회로 추천한 후보 중 딜러가 실전 매입 가치를 인정한 비율입니다.
  - **주의**: 이는 상사 매입 적합성에 대한 전문가 동의율일 뿐, 확정 수익률이나 절대적인 AI 모델 성능을 의미하지 않습니다.
- **가격 편차 (`avg_price_difference_krw`)**:
  - 엔카 매도 호가와 딜러가 제시한 실제 네고 가능가의 차이 (현장 네고 폭 학습용).
- **예상 수익 차이**:
  - AI 가상 순수익과 딜러가 산정한 실전 상품화/정비/탁송 비용을 반영한 예상 수익 간의 격차.
- **실제 수익률**:
  - 오직 차량 매입 후 최종 고객 판매까지 완전히 성사된 실거래 데이터에서만 산출.
- **표본수 명시 원칙**:
  - 표본이 3~8대에 불과하므로, 소표본임을 항시 명시하고 통계적 일반화로 과장하지 않음.
