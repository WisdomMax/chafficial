2. P0: 가짜 실차 사진 및 증빙 전면 정리

scripts/generate_clean_vehicle_assets.py는 차량을 실제 촬영한 것이 아니라 Pillow로 텍스트 이미지를 생성한 코드다.

해당 이미지는 다음 명칭으로 분류해야 한다.

DEMO_PLACEHOLDER

실차 사진이 아니다.

즉시 시행:

생성 이미지에서 '실차 인증', '촬영 원본', 'SHA-256 Verified', '100% 차종 일치 보증' 삭제

생성 이미지와 중립 플레이스홀더는 공개 매물 실차 사진으로 인정하지 않음

개발용 예시 이미지는 별도 테스트 환경에서 '예시 이미지'로 명확히 표시

기존 VehiclePhoto 기록을 추가 삭제하지 않음

이미 삭제된 사진은 백업·DB 기록·승인된 업로드 원본에서 복구 가능성 조사

백업이 없으면 복원했다고 주장하지 않음

실제 업로드된 사진은 출처, 차량 ID, 원본 해시, 촬영 권한, 관리자 검증 상태 보관

해시는 파일 무결성 확인용일 뿐 실제 차량 촬영이나 소유권의 증거가 아님

차량과 사진의 동일성은 별도 검증 절차를 통과해야 함

사진 검증 상태:

REAL_PHOTO_VERIFIED

REAL_PHOTO_PENDING

DEMO_PLACEHOLDER

NO_PHOTO

REJECTED

실차 사진이 없는 차량은 고객용 사이트에 공개하지 않는다. 이미 공개된 매물도 재검증한다.

개발용 디자인 미리보기에서는 예시 이미지를 사용할 수 있으나 고객 운영 API와 DB에서 완전히 격리한다.

3. P0: 사고·성능점검 SSOT 고도화

_normalize_accident_summary()는 같은 상태를 두 화면에 전달하도록 개선됐지만, 원본 JSON에 CLEAN 문자열이 있다는 이유만으로 VERIFIED_CLEAN을 부여하고 있다.

각 항목은 독립적으로 UNKNOWN / VERIFIED_CLEAN / VERIFIED_ISSUE 등 검증된 상태를 가진다.

실제 문서 검증이 없다면 VERIFIED를 부여하지 않는다.

외판 단순교환과 주요 골격 손상은 구분한다.

사고 여부만으로 누유·침수·외판 상태까지 정상으로 추정하지 않는다.

관리자 수정 기록과 공개 승인 근거도 보관한다.
