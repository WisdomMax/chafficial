## 3. 핵심 UI 개선 사항

### A. 20대 단위 페이지네이션 (Pagination)
- **1페이지 당 20대씩 노출**하여 100대 렌더링 시 브라우저 성능 저하 및 긴 스크롤 방지.
- 상단/하단 정보 바: `전체 100대 매물 중 1 - 20대 표시`.
- 1, 2, 3, 4, 5 넘버링 버튼 및 `‹`, `›` 버튼 완비.
- 필터 조건(제조사, 모델, 가격, 연식, 정렬, 검색어) 변경 시 `currentPage = 1`로 즉시 초기화.
- 페이지 변경 시 매물 결과 영역 상단으로 부드러운 스크롤 이동.

### B. 동적 모델 필터 및 카운트 배지
- 제조사 선택 시 해당 제조사의 세부 모델(현대: 아반떼 35대, 캐스퍼 10대 / 기아: 레이 25대, 모닝 25대, K3 5대)이 실시간 동적 집계되어 버튼 옆에 직관적으로 카운트 노출.
- 모바일 바텀시트 내 모델 선택 칩도 동일하게 연동.

### C. 5:3 비율 실차 사진 매핑
- 차량명만 적힌 그래픽 배너를 전면 배제하고, 800×480 해상도의 5:3 비율 실차 사진 21장을 각 차종에 매핑.
- 시안용 사진임을 알리는 `UI검수` 배지와 갤러리 내 `디자인 시안용 예시 사진` 캡션 명시.
