# CHA-FICIAL DIRECTIVE 069: 엔카(Encar) 벤치마크 1:1 대조 분석서

**참고 레퍼런스:** [엔카 공식 리뉴얼 보도자료 (fem.encar.com)](https://fem.encar.com/company/encar-news/615)  
**분석 목적:** 엔카의 고유 로고나 코드를 복제하지 않으면서, 한국 중고차 소비자가 가장 신뢰하고 직관적으로 정보를 탐색할 수 있는 **상용 쇼핑몰 수준의 정보 밀도와 시각 위계**를 차마트에 구현한 기술적 근거를 설명합니다.

## 1. 핵심 UI/UX 설계 원칙 대조

| 비교 항목 | 엔카 공식 리뉴얼 방향 | 차마트 DIRECTIVE 069 구현 | 벤치마크 일치도 및 기술적 근거 |
| :--- | :--- | :--- | :--- |
| **PC 기본 보기 (View)** | 가로 리스트형 기본 노출 (비교 탐색 용이성) | **가로 리스트형(`is-list`) 기본 적용** | 100% 반영. PC 1440 뷰포트에서 스크롤을 최소화하며 차량 가격, 연식, 주행거리를 한눈에 비교 가능 |
| **보조 보기 (Album View)** | 앨범형(카드 그리드) 선택적 제공 | **앨범형(`is-album`, 3열) 토글 스위치 제공** | 툴바 우측 `.cm-view-switch`에서 `aria-pressed` 기반 무결점 즉시 전환 지원 |
| **상단 영역 높이** | 검색창과 헤더를 슬림화하여 매물 가시성 확보 | **헤더 68px + 컴팩트 검색바 48px** | 상단 높이 150px 이내로 제한하여 1440×900 첫 화면에서 **매물 3대 이상 직접 노출** 달성 |
| **사진 비율** | 5:3 황금비 와이드 차량 썸네일 | **`aspect-ratio: 5 / 3` 통일** | 목록형(245×147px), 앨범형(100% w-5:3), 상세페이지(갤러리 5:3) 전 구간 통일 |
| **시각 위계 (Hierarchy)** | 사진 &rarr; 모델명 &rarr; 스펙 &rarr; 지역 &rarr; 정찰가 | **사진 &rarr; 모델명 &rarr; 스펙 &rarr; 인증태그 &rarr; 판매가** | 시선이 좌측 썸네일에서 우측 가격과 액션 버튼으로 자연스럽게 흐르는 가로 F-패턴 확립 |
| **배지 및 부가정보** | 과도한 배지 중첩 지양, 필수 진단만 간결화 | **무사고 진단 + 성능점검부 완료 2개로 절제** | 11px 마이크로 텍스트 남발과 불필요한 장식 제거, 가독성 높은 여백 확보 |
| **상세 페이지 가격 집중** | 우측 스티키 패널에 핵심 구매 조건 집중 | **상단 중복 가격 제거, 우측 350px 패널 집중** | 제목 영역의 가격 중복을 제거하고, 우측 사이드바에 차량가/월납입금/방문예약 단일 배치 |

| :--- | :--- | :--- |

| **모바일 (767px 이하)** | 좌측 사이드바 숨김, 바텀시트 필터, 모바일 1열 카드 | `.cm-listing-layout: block`, 사진 132px 썸네일 + 2열 그리드로 전환 |

## 3. 브랜드 아이덴티티 독창성 (Brand Differentiation)

- **엔카의 고유 색상(레드 계열) 및 코드 일체 배제**:
  - 차마트는 사용자 승인 공식 브랜드 컬러인 **화이트(`#FFFFFF`), 딥 차콜(`#171B1E`), 일렉트릭 라임(`#C8FF3D`)**을 100% 고수합니다.
  - 라임 컬러는 총 차량 대수 배지, 핵심 포인트 닷, 실차인증 태그 등 시선을 사로잡아야 할 5%의 핵심 포인트에만 절제되어 적용되어 고급스러운 스튜디오 감각을 제공합니다.
