### 2.2 [오류 발생 API] 온비드 물건 입찰결과목록 조회 (`getCltrBidRsltList2`)
- **수신 결과:** HTTP 200 / `resultCode = 11 (NO_MANDATORY_REQUEST_PARAMETERS_ERROR)`
- **원인 분석:**
  1. 기존 코드는 관례적 파라미터인 `_type=json`을 전송했으나, 온비드 차세대 표준은 **`resultType=json`**을 요구함.
  2. 또한 입찰결과목록 조회의 경우, 단순 자유 검색어(`cltrNm`) 외에 **`cltrMngNo` (물건관리번호)**가 필수로 요구되거나, **조회 대상 기간(예: `opngDtFrom` / `opngDtTo`)**이 필수일 가능성이 높음.

## 3. 기존 코드와 명세서의 차이 및 수정한 코드 내용

### 3.1 기존 코드의 결함
- ❌ 포맷 파라미터 오류: `_type: "json"` 사용 $\rightarrow$ 온비드 게이트웨이가 인식하지 못함.
- ❌ 차량 상세(3단계) 필수 누락: `pageNo`, `numOfRows`, `resultType`이 누락된 상태였음.

### 3.2 수정한 코드 (`scripts/spike_onbid_real_validation.py`)
공식 가이드 규격에 맞추어 요청 파라미터 딕셔너리를 전면 보정했습니다.

```python
# [1단계: 입찰결과목록] resultType 반영
params_step1 = {
    "serviceKey": service_key,
    "pageNo": "1",
    "numOfRows": "10",
    "cltrNm": "아반떼",
    "resultType": "json",  # _type -> resultType 정정
}

# [3단계: 차량상세] 공식 가이드 5대 필수 항목 100% 반영
params_step3 = {
    "serviceKey": service_key,
    "pageNo": "1",
    "numOfRows": "1",
    "resultType": "json",  # 필수(1)
    "cltrMngNo": target_cltr_mng_no,  # 필수(1)
    "pbctCdtnNo": target_pbct_cdtn_no,  # 옵션(0)

```

## 4. 아직 검증되지 않은 사항 (`UNVERIFIED`)

1. **`getCltrBidRsltList2` (입찰결과목록)의 공식 필수 파라미터 목록:**
   - 현재 사장님께서 제공해 주신 가이드는 `06_온비드_차량_물건상세`이므로, `01_온비드_물건_입찰결과목록`의 공식 Word/PDF 가이드 전문은 아직 미확인 상태입니다.
   - 포맷을 `resultType=json`으로 바꾼 것만으로 에러 11이 해소될지, 아니면 날짜/구분코드가 추가로 필수인지 여부는 공식 가이드 또는 단 1회의 재실증을 통해서만 최종 확인 가능합니다.
2. **과거 낙찰 차량의 상세 조회 가능 여부:**
   - 가이드 서두에 *"현재 입찰 중이거나 입찰 예정인 자동차 목록만 조회됩니다"*라고 명시되어 있어, 과거 이미 낙찰된 차량의 `cltrMngNo`를 `getCarDtlInf2`에 넣었을 때 정상 반환될지(`HISTORICAL_DETAIL_VERIFIED`)는 미검증 상태입니다.
