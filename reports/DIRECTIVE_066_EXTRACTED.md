2. P0 — 운영·스테이징 격리 범위 입증

경로를 나누고 운영 조회에 mode="prod"를 강제한 것은 확인 대상이다. 이것만으로 인프라의 ‘물리적 분리’까지 완료했다고 표현하지 않는다.

다음 실제 구성을 보고한다.

실행 프로세스 또는 배포 환경

DB 파일·연결 대상

사진 저장소 및 정적 파일 접근 경로

환경변수와 인증 경계

스테이징의 외부 접근 가능 여부

같은 프로세스·DB를 사용하는 경우 보고 명칭을 논리적 격리로 정정한다. 승인 없이 운영 인프라를 재구성하지 않는다.

운영 목록뿐 아니라 다음 우회 경로도 확인한다.

데모 ID를 지정한 운영 상세 조회

mode 변조 및 직접 URL 접근

사진 원본 URL과 다운로드 경로

견적서 생성·출력 경로

비공개·데모 차량의 상담 신청

목록에서 숨겨진 차량이 다른 공개 경로에서 노출되지 않아야 한다. 스테이징에서 생성한 견적서에는 시연용·실제 판매 견적 아님을 명확히 표시한다.

3. P0 — 사진 검증 및 연락처 근거 확인

검증 상태값과 SHA256 문자열의 존재만으로 실제 촬영·상업 이용 권한이 입증됐다고 판정하지 않는다.

사진 공개 조건에 필요한 근거와 검증 원장의 연결을 확인하고, 누락·불일치 시 공개를 차단한다. 사진이 없는 경우 임의의 대체 차량 사진을 사용하지 않는다.

전시장 주소·전화번호·제휴 관계는 각각 확인 근거를 남긴다. 특정 매매단지의 주소가 있다는 이유만으로 제휴나 방문 예약 가능성을 표현하지 않는다. 근거가 없는 항목은 고객 화면에서 제거하거나 확인된 범위로 문구를 수정한다.

5. P1 — A4 견적서의 실제 내용 보존 검수

페이지 수 1은 필요조건이며, 내용이 잘리지 않았다는 증거는 아니다.
