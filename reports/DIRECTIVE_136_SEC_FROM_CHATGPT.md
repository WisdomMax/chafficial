### TASK 1. 관리자 인증 긴급 보정
- `_worker.js`에 추가된 하드코딩 기본 관리자 인증값을 완전히 제거한다.
- Cloudflare Secret 미설정 시 모든 관리자 접근을 즉시 401 또는 503으로 차단한다.
- GitHub에 노출된 인증값은 폐기하고, 실제 운영에 사용된 경우 즉시 새 값으로 교체한다.
- `?token=` URL 인증을 폐기하고 적절한 관리자 세션 또는 서버 간 인증(Authorization: Bearer)만 허용한다.
- 동기화 API 인증과 관리자 조회 인증을 분리한다 (`CHAMART_SYNC_TOKEN` vs `CHAMART_ADMIN_TOKEN`).
- 브라우저 URL, 소스코드, 테스트 로그, 스크린샷에 비밀값을 남기지 않는다.
- 관리자 API는 실제 필요한 차량 정보만 반환하며, 비공개 데이터 접근 권한을 확인한다.

### TASK 2. 정보 노출 및 영향 범위 조사
- 관련 API의 접근 로그를 확인한다.
- 이전 기본 인증값을 이용한 비정상 접근 여부를 조사한다.
- 실제 정보 노출이 확인되면 영향 범위와 후속 조치를 별도 보고한다.
- 실서버에서 인증 없는 요청 및 폐기된 인증값 요청이 차단되는지 검증한다.
