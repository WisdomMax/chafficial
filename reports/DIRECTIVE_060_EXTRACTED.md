PART D. 개발·검증·보고
15. 작업 순서

PHASE 1: 디자인 시안

먼저 홈·목록·상세 PC/모바일 시안을 제작한다.

기존 화면과 비교해 무엇이 달라졌는지 확인한다.

PHASE 2: 실제 UI 구현

사용자 승인을 전제로 선정 시안을 적용한다.

차마트 고객 UI 디자인은 독립적으로 구축하되 차량 상세 콘텐츠의 공통 데이터와 차피셜 관리자 기능을 유지한다.

PHASE 3: 실측 검증

Playwright에서 실제 홈페이지와 차량 검색, 상세, 상담을 조작한다.

레이아웃 수치뿐 아니라 실제 캡처의 시각적 결함을 검수한다.

PHASE 4: 수정 반복

시각적으로 부족한 부분은 완료 선언하지 않고 수정한다.
