# CHA-FICIAL DIRECTIVE 049
## ENCAR SEOUL SOURCING FIRST
### 엔카 서울 실매물 자동 소싱 및 장한평 우선 선별 엔진

**발신:** ChatGPT 총괄 기술감독  
**수신:** Gemini Antigravity  
**우선순위:** P0, 최우선 개발 기능  
**기준:** DIRECTIVE 048 / GitHub `83b690e`

## 1. 핵심 목표 변경

DIRECTIVE 049의 최우선 개발 목표를 **엔카 실매물 자동 소싱**으로 지정한다.

초기 목표는 엔카에 등록된 실제 중고차 매물 정보를 차피셜 DB로 가져오는 것이다.

지역별 소싱 우선순위:

1. 장한평·장안평 매매단지 소재가 확인된 차량
2. 장한평 소재로 추정되지만 확인되지 않은 서울 차량
3. 서울 전체 차량

장한평 단위의 정확한 구분이 불가능하면 개발을 중단하지 말고 **서울 전체 매물 수집을 먼저 구현**한다.

서울 전체 매물도 실제 시장 분석에 유효한 데이터로 활용한다.

## 2. ENCAR Source Adapter 개발

`EncarSourceAdapter`를 개발하여 향후 다른 중고차 플랫폼도 같은 수집 구조로 연결할 수 있게 한다.

필수 기능:

- 엔카 검색 결과 조회
- 서울 지역 매물 필터
- 페이지별 매물 수집
- 차량별 원본 엔카 URL 저장
- 엔카 매물 고유 ID 추출
- 신규 매물 및 기존 매물 구분
- 중복 매물 제거
- 가격 및 상태 변경 추적
- 실패 기록, 재시도, 중단 후 재개

공식 제공 경로 또는 사용이 허용된 데이터 제공 경로를 우선한다.

외부 비공식 API 제공업체를 활용할 경우 서비스 권한, 데이터 재사용 조건, 비용을 확인한다.

접근 차단 우회나 무단 대량 수집은 구현하지 않는다.

CSV 수동 입력은 예비 경로로만 제공하고, 자동 소싱 구현 여부를 별도로 보고한다.

## 3. 실제 매물에서 추출할 필드

필수:

- source = ENCAR
- source_listing_id
- source_url
- manufacturer
- model
- trim
- model_year
- mileage_km
- price_krw
- fuel_type
- transmission
- raw_region
- raw_seller_location
- observed_at
- ingested_at
- last_seen_at
- listing_status
- source_confidence

매물에 없는 정보는 UNKNOWN 또는 NULL로 기록한다.

판매자·매매단지 명칭, 주소, 구 단위 지역은 실제 제공되는 경우에만 저장한다.

엔카에 공개된 원본 링크로 실제 매물을 확인할 수 있어야 한다.

차량 사진은 우선 링크와 이용 권한만 관리한다. 소싱했다고 광고용 사진 사용 권한을 취득한 것으로 간주해서는 안 된다.

## 4. 장한평 소재지 식별

주소, 판매자 정보, 매매단지 명칭 등 확인 가능한 근거를 이용해 지역을 분류한다.

분류 상태:

- JANGANPYEONG_CONFIRMED
- JANGANPYEONG_CANDIDATE
- SEOUL_OTHER
- SEOUL_UNSPECIFIED
- LOCATION_UNKNOWN

'장한평', '장안평' 등의 표기를 정규화한다.

판매자 소재지와 차량 실제 전시장 위치를 구분한다.

서울이라는 사실만으로 장한평 매물로 확정하지 않는다.

후보 판단에는 원본 값과 판정 사유를 기록한다.

## 5. 매물 스냅샷 및 가격 추적

같은 매물을 주기적으로 다시 관측하여 다음 변화 이력을 축적한다.

- 최초 관측 가격
- 최신 관측 가격
- 가격 인하·인상
- 관측 기간
- 마지막 관측 시각
- 검색 결과에서의 노출 여부

한 번 보이지 않는다는 이유만으로 판매 완료로 판단하지 않는다.

매물 상태는 ACTIVE, NOT_SEEN, REMOVED_UNCONFIRMED, SOLD_VERIFIED 등으로 구분한다.

수집 주기는 처음에는 하루 1회로 설정 가능하게 하며, 허용된 접근 한도와 소스 갱신 정책을 준수한다.

## 6. 소싱 관리 화면

차마트 관리자가 실제 엔카 매물을 확인할 수 있도록 간단한 소싱 화면을 구현한다.

화면 필수 항목:

- 엔카 서울 수집 매물 수
- 장한평 확인 매물 수
- 장한평 후보 매물 수
- 신규 등록 매물 수
- 가격 인하 매물 수
- 최근 수집 성공·실패 상태

필터:

- 지역
- 제조사/모델
- 연식
- 가격
- 주행거리
- 가격 인하 여부
- 신규 등록 여부

각 매물에서 엔카 원본 상세 페이지를 열 수 있도록 한다.

## 7. 실제 판매 매물과 시장 관측 매물 분리

엔카에서 가져온 차량은 기본적으로 `MARKET_OBSERVED`로 등록한다.

시장 관측 매물은 차마트의 판매 재고가 아니다.

장한평 파트너 딜러의 실제 취급 차량으로 확인하고 필요한 권한을 승인받은 경우에만 판매·영상 제작 후보로 전환한다.
