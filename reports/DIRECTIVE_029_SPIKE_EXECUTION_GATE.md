## 2. 공공데이터포털 활용신청 공식 서비스 목록

실제 단일 차량 검증을 위해 공공데이터포털(data.go.kr)에서 활용신청(개발계정: 신청 즉시 자동 승인)해야 하는 3대 핵심 API 서비스입니다.

1. **`한국자산관리공사_차세대 온비드 물건 입찰결과목록 조회서비스`**
   - 용도: 과거 개찰 완료된 물건 중 낙찰된 차량 목록 탐색 (`cltrMngNo`, `pbctCdtnNo` 확보)
2. **`한국자산관리공사_차세대 온비드 물건 입찰결과상세 조회서비스`**
   - 용도: 해당 물건의 최종 실제 낙찰가격(`sucsfBidAmt`) 및 개찰일시, 공매 회차 확인
3. **`한국자산관리공사_차세대 온비드 차량 물건상세 조회서비스`**
   - 용도: 해당 물건관리번호로 과거 낙찰 차량의 제원(주행거리, 연식, 옵션)이 여전히 정상 응답되는지 역추적(경로 B) 검증

## 3. 인증키 발급 및 안전한 로컬 보관 방법

- **발급처:** [공공데이터포털 (data.go.kr)](https://www.data.go.kr) 로그인 후 상기 서비스 각각 [활용신청] 클릭 (즉시 승인)
- **보관 원칙:**
  - 채팅창이나 GitHub 보고서에 인증키를 노출하지 않습니다.
  - 차피셜 프로젝트 루트 디렉터리의 로컬 `.env` 파일에 아래와 같이 환경변수로 안전하게 설정합니다:
    ```bash
    # .env (로컬 환경 전용, .gitignore 적용 대상)
    DATA_GO_KR_API_KEY="발급받은_Decoding_인증키"
    ```

## 4. 단일 차량 실증(Spike) 예상 호출 횟수 및 실행 계획

- **검증 대상:** 아반떼 CN7 단 1대 (과거 낙찰 기록 부재 시 최근 대량 낙찰 차종 1대로 대체)
- **최소 호출 계획 (총 3회 이내):**
  1. `1회차`: 입찰결과 목록 API 호출 (차량 낙찰 물건 1건 및 `cltrMngNo` 추출)
  2. `2회차`: 입찰결과 상세 API 호출 (해당 물건의 실제 낙찰가격 `sucsfBidAmt` 확인)
  3. `3회차`: 차량 물건상세 API 호출 (해당 물건의 주행거리·연식 역방향 Join 성공 여부 확인)
- **성공 판정 기준 (독립 평가):**
  - `RESPONSE_VERIFIED`: 실제 200 OK 응답 수신
  - `JOIN_VERIFIED`: `cltrMngNo` + `pbctCdtnNo` 기반 1:1 결합 성공
  - `PRICE_VERIFIED`: 실제 유효 낙찰가격 필드 확인
  - `HISTORICAL_DETAIL_VERIFIED`: 과거 낙찰 차량의 상세 스펙 역조회 성공

## 5. 사장님(사용자) 승인 요청 사항

사장님께서 공공데이터포털에서 인증키를 발급받으신 후:
1. `.env` 파일에 `DATA_GO_KR_API_KEY="키값"` 등록
2. 채팅창에 **"온비드 단일 차량 실증 실행 승인"**을 지시해 주시면,
3. 차피셜 엔진이 엄격히 통제된 단 3회의 호출 스크립트를 실행하여 실제 데이터 응답 원문을 검증하고 최종 실증 보고서를 작성하겠습니다.
