### 지침 전문

1. `tests/test_directive_136_sec.py`의 Case 3에서 실제 `CHAMART_ADMIN_TOKEN`을 URL에 넣어 보내는 행위를 즉시 제거하라. 유효한 토큰의 URL 인증 거부 여부는 운영 서버가 아닌 격리된 Worker 테스트에서 합성 토큰으로 검증하라.
2. 관리자 검수 화면 생성 스크립트에서 토큰을 `page.evaluate()` 내부 문자열에 삽입하지 말라. 서버 측 인증 요청으로 데이터를 가져와 격리된 관리자 검수 환경에서 화면을 구성하라.
3. 위 테스트에 사용됐을 가능성이 있는 운영 관리자 토큰을 최소 256비트 암호학적 난수로 교체하라. 새 토큰은 Cloudflare Secret에만 등록하고 소스코드·URL·로그에 출력하지 말라.
4. 관련 접근 로그와 배포 환경을 점검하고, 확인 가능한 범위와 로그 보존 한계를 사실대로 보고하라. 로그가 없으면 '외부 접근이 없었다'고 단정하지 말라.
5. 수정 후 인증 없는 요청 401, 폐기 토큰 401, 관리자 정상 인증 200, 기존 동기화 정상 작동만 검증하라.
6. 이번 작업으로 DIRECTIVE 136-SEC 보안 트랙을 종료한다. 추가 기능 개발이나 불필요한 완료 보고 반복은 금지한다. 차량 공개 상태는 변경하지 않는다.
