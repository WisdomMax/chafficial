# CHA-FICIAL DIRECTIVE 136
## 실제 판매 운영을 위한 마지막 연결 및 게시 승인 상태 보존

**기준 커밋:** `5c529a2`  
**감독 판정:** 실시간 직영 매물 연동 코드 개선 인정, 운영 E2E 최종 합격 보류

### TASK 1. 관리자 공개 승인 상태 보호
- 현재 `shouldAutoPublish=false` 때문에 기존 승인 차량이 동기화 후 다시 비공개되는 결함 수정
- 신규 미승인 차량은 비공개 등록
- 관리자가 승인한 차량은 가격·제원 업데이트 후에도 공개 승인 상태 유지
- SOLD, 광고중지, 승인 취소 시에는 즉시 비공개
- 64노3143은 사용자 명시 승인 전까지 보호

### TASK 2. 실시간 판매 상태 추적
- 직영 실시간 목록과 과거 캐시 목록을 정확히 분리
- 최신 원본에 없는 차량은 상태 미확인으로 분류하여 재조회
- 광고중지와 실제 판매완료를 서로 구분
- 판매 상태가 불명확한 차량은 고객에게 판매 중이라고 단정하지 않음
- 과거 데이터가 최신 판매 상태를 덮어쓰지 못하도록 차단

### TASK 3. 운영 E2E 테스트 바로잡기
- launchd 등록 여부가 False면 테스트 FAIL
- 실제 판매 상태 변경 검증 조건 추가
- D1 전송 성공 후 원격 DB를 다시 조회하여 원본 데이터와 비교
- 실제 고객 매물을 변경하지 않는 격리된 테스트 환경 사용
- 테스트 성공 로그와 운영 성공 로그 구분

### TASK 4. 실제 관리자 검수 화면
- D1의 실제 비공개 차량 데이터를 인증된 관리자 API로 읽어 표시
- 하드코딩된 차량 데이터나 브라우저 주입으로 운영 검증을 대체하지 않음
- 차량번호, 가격, 주행거리, 상사명, 사진 개수 및 권한 상태 정확히 확인
- 미확인 정보는 '확인 대기'로 표시

### TASK 5. 사용자 승인 후 운영할 수 있는 구조 완성
- 최초로 승인한 제휴 상사 및 게시 범위를 관리자가 설정
- 실제 동의 증빙과 판매 권한이 확인된 차량에만 자동 공개 정책 적용
- 이후 신규 매물은 사전 승인된 범위 내에서 자동 등록
- 관리자 승인 취소 및 판매완료는 자동으로 공개 중단
- 사용자 최종 승인 전에는 어떤 차량도 새로 공개하지 않음

**최종 합격 기준:** 실제 판매 권한이 확인된 차량을 한 번 승인하면 차마트에 정상 노출되고, 가격 변경 시에도 노출을 유지하며, 판매완료 시에는 즉시 사라지는 전 과정을 입증한다.
