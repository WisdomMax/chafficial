과도한 카드, 배지, 굵은 폰트, 아이콘 중심의 AI 생성형 디자인 잔존

이번 057은 위 결함 해결과 차마트 외부 사이트의 상용 디자인 품질을 핵심 목표로 한다.

PART A. P0 운영 데이터 및 공개 신뢰성
2. 공개 매물 검증 통합

차마트 고객 공개 목록과 상세 API가 반드시 동일한 중앙 공개 검증 정책을 사용하도록 수정한다.

적용 대상:

/api/chamart/vehicles

/api/chamart/vehicles/{id}

/chamart

/cars/{id}

공개 필수조건:

실제 판매 가능한 차량

소유·판매 및 광고 권한 확인

DEMO가 아닌 실제 차량

관리자 게시 승인

판매 권한 유효

검증된 실제 차량 사진 최소 1장

사진 사용 권한 확인

현재 파일명에 placeholder가 없는지, caption에 DEMO_PLACEHOLDER가 없는지만으로 실제 사진을 검증하는 방식을 폐기한다.

실제 DB에 다음 정보가 있어야 한다.

photo_verification_status

verified_at

verified_by

source_asset_id

vehicle_id

original_file_hash

usage_rights_status

고객 API는 승인된 실제 사진만 반환한다.

동일한 공개 검증 정책을 목록·상세에 적용한다.

비공개 차량의 직접 URL 접근도 반드시 차단한다.

테스트 데이터는 별도 DB 및 명시적인 데모 환경에서 관리한다.

3. 성능점검 증빙 확인

현재 inspection_document_id와 inspection_date 문자열만 있어도 검증 완료 처리되는 문제를 수정한다.

다음이 실제로 확인된 경우에만 VERIFIED 판정을 부여한다.

등록된 실제 문서 원본

문서에 기재된 차량 식별정보 일치

검증된 문서 종류·발행기관

담당자 검토 및 승인

문서와 개별 점검 항목의 연결

보험이력과 타이어·소모품 상태는 각각 독립적으로 검증한다.

증빙 없이 사고·침수·누유·보험이력을 정상으로 추정하지 않는다.

차체 SVG는 실제 부위별 검증값만 반영한다.

4. 가짜 운영 정보 전면 제거

현재 고객 푸터와 상담 영역의 임시값을 전수 감사한다.

대상:

사업자등록번호

대표자

법인명

통신판매업 신고번호

고객센터 전화번호

이메일

전시장 주소

판매 담당자

금융·보증·환불 관련 약속

실제 확인되지 않은 정보를 임의로 작성하지 않는다.

정보가 필요한 경우 차피셜 관리자 설정에 입력·검증 항목을 마련한다.

필수 정보가 확인되지 않으면 공개 배포를 막고 운영 준비 상태로 유지한다.

고객 푸터에서 차피셜 관리자 페이지로 연결되는 링크를 제거한다.

이용약관과 개인정보처리방침은 실제 해당 문서로 연결한다. 임시로 홈페이지로 돌아가게 하는 링크는 완료로 인정하지 않는다.

5. 카카오 상담 연결

현재 https://pf.kakao.com 일반 접속은 차마트 1:1 상담이 아니다.

차마트의 실제 카카오 채널 ID가 설정된 경우 공식 연결 방식으로 상담을 연다.

설정되지 않았으면 고객 페이지에서 버튼을 숨긴다.

실제 상담 채널이 없는 상태에서 연결됐다고 표시하지 않는다.

6. 브랜드 원칙

차피셜: 내부 운영 프로그램

차마트: 외부 고객용 전문 중고차 판매 사이트

고객 사이트 로고 및 주요 브랜드 표기는 반드시 차마트를 사용한다.

실제 기업이 운영하는 전문 중고차 사이트

높은 정보 신뢰도

뛰어난 차량 탐색 경험

사진 중심의 깔끔한 상품 구성

모바일 구매 편의성

과도한 AI 생성형 UI 스타일 제거

차마트 고객용 사이트 전체를 차피셜 관리자 대시보드와 독립적으로 디자인한다.
